# Final approved DT Exchange identity

The user approved `Approved_Reference.jpeg` as the permanent visual benchmark in Phase 3. This explicit direction supersedes the older Phase 1 navy-to-mint single-gradient monogram.

The canonical implementation is `brand/dt-monogram.svg`: a simple slanted mint/teal D, slightly connected to a premium-blue T. It contains no currency symbol, arrows, circles or surrounding symbols. Identical SVG bytes are used in mobile and admin assets. Native iPhone, Android and web launcher images are rasterized from that vector using `mobile/tool/brand_hosts.py`.

The reference was supplied as a raster image, not an editable original logo. The SVG is a faithful vector implementation of that approved shape and color direction; pixel-identical reproduction of an unavailable original vector is not claimed. The existing Phase 2 layouts, tokens, buttons, component shapes, navigation and animation language are retained. No marketing claim, payment address or personal contact details from the reference are used operationally.

Future phases must preserve this approved identity and the canonical color tokens. The reference does not authorize new real-money features.
